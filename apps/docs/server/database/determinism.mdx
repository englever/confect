description: "How Confect keeps queries cacheable by default."
---

Convex caches query results based on their arguments and the data the handler reads. Reading real wall-clock time through `Date.now()` or another API that uses it makes time a dependency and can reduce caching. See Convex's [caching recommendations](https://docs.convex.dev/production/best-practices/).

Effect programs read the clock internally when they log or open spans. To keep those operations from observing real time, Confect gives query handlers an Effect `Clock` with constant unsafe accessors:

- `currentTimeMillisUnsafe` returns `0`.
- `currentTimeNanosUnsafe` and `monotonicTimeNanosUnsafe` return `0n`.
- The effectful `Clock.currentTimeMillis`, `Clock.currentTimeNanos`, and `Clock.monotonicTimeNanos` accessors still read real time.

Confect does not stub `Date.now()`. A bare `Date.now()` call inside a query returns real wall-clock time on both the mock and local backends.

Mutations and actions use the normal Effect clock. Their unsafe accessors also read real time.

## Effect operations that avoid real time

The following use the query clock's constant unsafe accessors:

- `Effect.log`/`Effect.logInfo`/etc.
- `Effect.withSpan` and other tracing operations

Elapsed-time measurements through those accessors, such as `Effect.timed`, report zero duration in queries.

## Reading real time

Use Effect's `Clock` service when you need the real timestamp:

```ts
import * as Clock from "effect/Clock";
import * as Effect from "effect/Effect";
import { DatabaseReader } from "./confect/_generated/services";

Effect.gen(function* () {
  const reader = yield* DatabaseReader;
  const rows = yield* reader.table("notes").index("by_creation_time").collect();
  const fetchedAt = yield* Clock.currentTimeMillis;

  return { fetchedAt, rows };
});
```

Reading `Clock.currentTimeMillis`, `Clock.currentTimeNanos`, or `Clock.monotonicTimeNanos` observes real time, as does a bare `Date.now()` call. Each opts into Convex's time-dependent caching behavior.

## Preferring cacheable alternatives

If you don't need sub-second accuracy inside the query, follow Convex's [recommended patterns](https://docs.convex.dev/production/best-practices/) to preserve caching:

- Pass a coarse timestamp (e.g. rounded to the minute or hour) as a query argument from the client.
- Maintain a boolean or status field on the document, updated by a scheduled function or mutation.
- Compute time-dependent values in a mutation or action and persist the result.

## Library code that reads time

A library that calls `Date.now()` during a query sees real time. Confect's constant unsafe Effect clock does not affect those calls. Check time reads in libraries you use inside queries when you need predictable caching.
