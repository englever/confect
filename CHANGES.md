# Fork changes

This is the hand-maintained record of changes carried by `englever/main` beyond
its upstream release base. Update it in every fork PR with what changed, why,
the fork PR number, changeset coverage, and upstream intent or proposal.
It complements package changelogs; it is not generated by Changesets.

The initial inventory covers all 22 merged fork PRs through
[`57ae68aa`](https://github.com/englever/confect/commit/57ae68aab7ff77fdea2e3a442a3bdf56324a1d3d),
based on upstream 10.2.0 (`1f75cb80`). It comes from
`git log --oneline origin/englever/main ^upstream/main`, the merged PRs, and
`.changeset/`. A backport remains listed even after it reaches upstream `main`
until the fork adopts a release containing it. PR numbers below link to
**englever/confect** unless explicitly marked upstream.

Upstream status was checked on 2026-10-16. **Planned** marks a product patch
covered by Edcell's ADR 0002 plan to propose fork capabilities upstream; it does
not imply that a proposal has been submitted or accepted. **Unrecorded** means
the reviewed PR and changeset do not establish submission intent. Fork-specific
publishing and branch automation stay **fork only**. Upstream submissions go
through Gagan.

## Component authoring and contracts

### [#5](https://github.com/englever/confect/pull/5) Author Convex components

Add component codegen and dev modes, published contracts, `Component.bind`,
scoped services, schemas and IDs, HTTP routes, and test registration. Components
can expose decoded arguments, results, and declared errors across installation
boundaries while retaining a vanilla Convex wire API. Port upstream's component
work to stable Effect and prove nested isolation, errors, pagination, env, crons,
and storage on the supported backends.

Changeset: `add-confect-components.md`.
Upstream: port of [upstream #646](https://github.com/rjdellecese/confect/pull/646),
which remains open; fork-specific follow-up submission is unrecorded.

### [#11](https://github.com/englever/confect/pull/11) Type component callbacks

Add callback contracts, stored handle schemas, and host handle creation so a
component can call its host with checked args, returns, and declared errors.
Compare compiled validators before creating Confect handles; equal validators
cannot distinguish every codec or refinement. Preserve return and error codecs
on references, include middleware errors, and decode declared errors by tag.

Changeset: `add-component-callbacks.md`.
Upstream: planned; no linked proposal verified.

### [#18](https://github.com/englever/confect/pull/18) Preserve component schema and ref types

Keep struct fields, recursive schemas, and decoded ID-free class types when
rebinding component codecs. Add scoped system-table ID factories and
`Ref.Callable` for helpers accepting public and bound internal refs. Reject ref
assignments that omit required arguments so shared handlers retain their calling
contract.

Changeset: `component-authoring-contracts.md`.
Upstream: planned; no linked proposal verified.

### [#19](https://github.com/englever/confect/pull/19) Cancel component jobs and gate pagination

Expose `Scheduler.cancel` for component-scoped scheduled IDs. Reject native
component `.paginate()` at compile time and direct callers to `QueryStream.paginate`
for index queries, because native pagination is unavailable in components.
Application schemas keep native pagination.

Changeset: `scoped-scheduler-cancel-pagination.md`.
Upstream: planned; no linked proposal verified.

## Backend declarations and HTTP routing

### [#14](https://github.com/englever/confect/pull/14) Declare a backend in `confect/`

Add `Env`, `App`, `Auth`, `Http`, and `Manifest`. Generate Convex configuration,
auth, HTTP entry points, and an import-free deployment manifest from the backend's
declaration so handlers, component mounts, and infrastructure share one contract.
Watch declarations in dev mode and reject conflicting routes and hand-written
owned outputs. Components can declare their env and mounts the same way.
Raise core's Convex peer floor to 1.39.0 for component env declarations.

Changeset: `backend-declaration.md`.
Upstream: planned; no linked proposal verified.

### [#7](https://github.com/englever/confect/pull/7) Label reflected HTTP routes

Accept `{ api }` on application and component HTTP routers so completion logs and
the dashboard show endpoint patterns such as `GET /users/:id` instead of a
catch-all. Preserve Effect dispatch, native route precedence, and fallback labels,
including empty APIs and prefixed component mounts.

Changeset: `label-http-api-routes.md`.
Upstream: planned; no linked proposal verified.

## Alchemy deployment

### [#2](https://github.com/englever/confect/pull/2) Deploy Convex through Alchemy

Add the optional `@confect/alchemy` package for cloud projects, deployments, keys,
environment variables, and code pushes. `Confect.Backend` runs installed codegen
before deployment. This lets applications use Alchemy stacks without introducing
infrastructure dependencies into the runtime packages. Retain cloud projects and
deployments by default. Include the pnpm launcher metadata refresh from the port.

Changeset: `add-alchemy-integration.md`.
Upstream: port of [upstream #735](https://github.com/rjdellecese/confect/pull/735),
which remains open.

### [#10](https://github.com/englever/confect/pull/10) Run the same stack locally

Resolve Convex resources to provider-owned anonymous local backends under
`alchemy dev`, preserving data, identity, and ports across sessions. This removes
the separate local setup and cloud credentials from development. Serialize cloud
and local pushes per deployment for processes sharing a user cache to prevent
schema-overwrite races. Document port selection, data ownership, recovery, and
lifecycle errors; make the deployment's `region` output optional for local use.

Changeset: `alchemy-local-providers.md`.
Upstream: planned; no linked proposal verified.

## CLI generation and recovery

### [#6](https://github.com/englever/confect/pull/6) Typecheck large generated specs

Leave generated spec builder chains untyped internally while preserving the
result's public type. Application and component projects with 47 or more function
groups can typecheck without TypeScript's excessive-instantiation error.

Changeset: `fix-spec-chain-depth.md`.
Upstream: backport of merged
[upstream #774](https://github.com/rjdellecese/confect/pull/774); retain until a
release containing it becomes the fork's base.

### [#15](https://github.com/englever/confect/pull/15) Reject component Node groups early

Report the group and Convex's Node.js restriction during component codegen and
dev, before generating unusable output. Preserve application Node support and
restore previous generated component output after a rejected edit.

Changeset: `reject-component-node-groups.md`.
Upstream: planned; no linked proposal verified.

### [#23](https://github.com/englever/confect/pull/23) Release watchers before rollback

Close the generated-directory watcher before restoring dev output and resume it
afterward. Retry busy removals briefly, including temporary CLI project cleanup,
so Windows handles do not immediately abort recovery. Exhausted retries report a
tagged failure with the path, attempts, and cause.

Changeset: `quiet-windows-restore.md`.
Upstream: unrecorded; no linked proposal verified.

### [#9](https://github.com/englever/confect/pull/9) Register component kits and fetch mounted HTTP

Add `TestConfect.layer` options for component registration and explicit HTTP mounts
so kits initialize before test programs and fetches run in the selected
installation. Preserve mount-specific URLs and database isolation. Document the
need for fresh router loaders and the shared process env and module-cache limits.

Changeset: `testconfect-component-kits.md`.
Upstream: planned; no linked proposal verified.

### [#16](https://github.com/englever/confect/pull/16) Correct query clock documentation

Explain that bare `Date.now()` reads real time while the query Effect clock's
unsafe accessors return constants. Describe time-dependent caching without
promising an eviction frequency, so readers do not rely on a nonexistent stub.

Changeset: none; website-only documentation.
Upstream: unrecorded; no linked proposal verified.

### [#20](https://github.com/englever/confect/pull/20) Rebaseline reference type benchmarks

Measure and replace stale `Refs` instantiation baselines on the pinned TypeScript
7 toolchain after the callback ref changes. Keep the 20% threshold so accumulated
baseline drift no longer consumes the regression budget.

Changeset: none; benchmark-only change.
Upstream: unrecorded; no linked proposal verified.

### [#21](https://github.com/englever/confect/pull/21) Allow slower Windows CLI tests

Set the CLI test and hook timeouts to 15 seconds on Windows after a CI run
exceeded the five-second default. Other platforms keep their defaults.

Changeset: none; test configuration only.
Upstream: unrecorded; no linked proposal verified.

### [#22](https://github.com/englever/confect/pull/22) Bound nested-binding fixture requests

Split nested component writes and reads into separate requests per installation
so the local backend's system-time budget is not spent on six traversals in one
mutation. Finish both writes before reads and retain the isolation assertions;
production bindings and backend timeouts are unchanged.

Changeset: none; test fixtures only.
Upstream: unrecorded; no linked proposal verified.

## Fork integration and publishing

### [#25](https://github.com/englever/confect/pull/25) Gate fork publication and exercise a declared consumer

Publish only after every check in the same commit's Packages workflow passes.
Make the publisher reusable instead of starting an independent push run, and
route manual publication through Packages so it has the same gate. Keep direct
published-version checks available without publication.

Exercise the packed PR build in a fresh strict-peer consumer before publication.
Generate backend, auth and HTTP declarations and a Confect-authored component
mounted at `/counter`. Call the component through the host, round-trip a callback
with argument and return codecs, reject mismatched callback args, and fetch the
host and component HTTP routes. Keep the published-build alias check after
publication.

Changeset: none; tooling only.
Upstream: fork only.
